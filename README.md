Minha atuação na programação é voltada ao desenvolvimento de software, com foco em aplicações back-end e na construção de soluções para necessidades reais. Tenho experiência prática com PHP, Laravel, SQL e tecnologias relacionadas ao desenvolvimento web, aplicadas em projetos próprios.

Busco desenvolver aplicações com código organizado, estrutura consistente e funcionalidades bem definidas, considerando arquitetura, relacionamentos entre dados, regras de negócio e manutenção do software. Tenho interesse especial em desenvolvimento back-end, engenharia de software e construção de sistemas, com atenção às boas práticas e à qualidade das soluções.

*My work in programming focuses on software development, especially back-end applications and solutions to real needs. I have hands-on experience with PHP, Laravel, SQL, and related web technologies, applied in personal projects.*

My interests include back-end development, software engineering, and building systems, with a focus on good practices and solution quality.*
