Olá, eu sou o **Felipe**. Sou estudante de programação e me interesso principalmente por desenvolvimento de software, com foco em **back-end**.
 
Venho construindo projetos próprios para praticar lógica de programação, arquitetura de aplicações, organização de código, banco de dados e o desenvolvimento de funcionalidades reais. Hoje, minha stack web gira em torno de **PHP**, **Laravel** e **Livewire**, com **MySQL** para os dados e **JavaScript**, **Bootstrap** e **Sass** na interface.
 
> Hi, I'm **Felipe**, a programming student interested in software development, with a focus on **back-end**. ## Objetivos / Goals
 
Meu foco agora é ir além de fazer o código funcionar: quero entender como as partes de uma aplicação se encaixam. Isso passa por afiar a lógica de programação, aprofundar PHP e Laravel e organizar melhor a arquitetura do que construo. Também quero ganhar mais firmeza em SQL e bancos de dados, que sustentam grande parte do back-end.
 
Para isso, a prática continua sendo projetos próprios, cada vez mais completos e com funcionalidades próximas de problemas reais, estudando boas práticas de engenharia de software ao longo do caminho.
 
> My focus right now is to go beyond making code work: I want to understand how the parts of an application fit together. That means sharpening my programming logic, going deeper into PHP and Laravel, and organizing the architecture of what I build more carefully. I also want to get more solid in SQL and databases, which support a large part of back-end work.
>
> To get there, practice remains personal projects that are more complete each time and closer to real problems, while studying software engineering best practices along the way.
